    Spuštění aplikace

    Požadavky

    • Windows 10 nebo novější
    • Python 3.12+ a virtuální prostředí .venv
    • SQLite – žádná samostatná databázová služba se neinstaluje

    Spouštěcí soubor start-dev.bat

    V kořeni projektu spusťte start-dev.bat. Skript provede migrace, zajistí vývojový účet přes ensure_dev_admin a spustí server na portu 8000.

    Adresa: http://127.0.0.1:8000/

    Databáze SQLite

    Data jsou v souboru db.sqlite3 v kořeni projektu. PostgreSQL ani Linuxové služby se nepoužívají.
